# 교재 재고관리

입고와 출고를 기록하면 교재별 현재 재고가 자동으로 계산되는 사이트입니다.
데이터는 Supabase에 저장하고, 사이트는 GitHub Pages로 띄웁니다.

## 파일

| 파일 | 역할 |
|---|---|
| `index.html` | 화면 |
| `app.js` | 동작 (Supabase에 저장하고 읽어 오기, 로그인) |
| `config.js` | Supabase 프로젝트 주소와 공개용 키 |
| `schema.sql` | Supabase에 만든 표의 SQL (이미 적용됨) |

## 설치 순서

Supabase와 GitHub 화면의 메뉴 이름은 가끔 바뀝니다. 아래 이름과 조금 다르면 비슷한 이름을 찾아 주세요.

### 1. Supabase 프로젝트 (완료)

"HIFS textbook inventory" 프로젝트를 서울 지역에 만들고 `schema.sql`을 적용해 두었습니다. 다시 실행할 필요는 없습니다. `schema.sql`은 어떤 표가 있는지 보는 기록용입니다.

### 2. 공용 계정 만들기 (직접 해야 합니다)

Supabase 대시보드에서 "HIFS textbook inventory" 프로젝트를 엽니다.

1. **Authentication → Users → Add user → Create new user**에서 공용으로 쓸 이메일과 비밀번호를 정합니다. **Auto Confirm User**를 켜 둡니다. 이메일은 실제로 받을 수 있는 주소가 아니어도 됩니다.
2. **Authentication → Sign In / Providers**에서 **Allow new users to sign up**을 끕니다. 이걸 꺼야 다른 사람이 마음대로 계정을 만들 수 없습니다.

### 3. config.js (완료)

프로젝트 주소와 publishable 키를 넣어 두었습니다. 고칠 필요 없습니다.

`service_role` 또는 `secret` 키는 절대 넣지 마세요. 그 키는 로그인 없이 모든 데이터를 읽고 지울 수 있습니다.

### 4. GitHub에 올리고 사이트 띄우기

1. GitHub에서 새 저장소를 만듭니다. 무료 요금제에서 GitHub Pages를 쓰려면 **Public**이어야 합니다.
2. **Add file → Upload files**로 파일 네 개와 이 README를 올립니다.
3. **Settings → Pages**에서 Source를 **Deploy from a branch**, Branch를 **main / (root)**로 정하고 저장합니다.
4. 1~2분 뒤 같은 화면에 사이트 주소가 나옵니다. (`https://아이디.github.io/저장소이름/`)

### 5. 처음 사용

1. 사이트 주소로 들어가 공용 계정으로 로그인합니다.
2. **업체 관리**에서 업체를 먼저 등록합니다.
3. **재고 현황 → 새 교재 등록 → 엑셀로 한 번에**에서 예시 엑셀 파일을 받아 교재를 적고 올립니다.

## 보안은 이렇게 되어 있습니다

- 저장소가 공개라서 코드와 `config.js`의 anon 키는 누구나 볼 수 있습니다. 이 키는 공개를 전제로 만든 키입니다.
- 데이터는 로그인한 계정만 읽고 쓸 수 있게 Supabase에서 막아 두었습니다 (`schema.sql`의 6번). 로그인하지 않으면 키가 있어도 아무것도 보이지 않습니다.
- 따라서 실제 열쇠는 공용 계정의 비밀번호입니다. 길게 정하고, 사람이 바뀌면 **Authentication → Users**에서 비밀번호를 바꿔 주세요.
- 공용 계정 하나를 같이 쓰기 때문에 누가 기록했는지는 남지 않습니다.

## 알아 둘 점

- 재고보다 많은 출고는 화면에서도 막고, 서버에서도 한 번 더 막습니다. 두 사람이 동시에 출고를 기록해도 재고가 0보다 작아지지 않습니다.
- 다른 사람이 기록한 내용은 **새로고침** 버튼을 누르거나 화면으로 돌아올 때 반영됩니다.
- 재고 현황의 "최근 입출고"는 최근 100건만 보여 줍니다. 전체 기록은 **입출고 내역** 탭에서 기간을 골라 보고, 수정·삭제할 수 있습니다 (한 번에 500건까지).
- 교재 수정·삭제는 교재 상세 창이나 **교재 목록** 탭에서 합니다. 업체 삭제는 아직 화면에 없어서, 필요하면 Supabase **Table Editor**에서 직접 지울 수 있습니다.
- Supabase 무료 요금제는 한동안 사용이 없으면 프로젝트가 일시정지될 수 있습니다. 그럴 때는 Supabase 대시보드에서 다시 켜면 됩니다.
